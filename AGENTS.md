# How the team works together

The Epilogue Navigator is the front door. It runs the onboarding, writes the profile, and stays across the whole journey.

| Moment | Lead skill | It draws on |
|---|---|---|
| First conversations, onboarding | Epilogue Navigator | nothing yet; creates profile |
| Working through questions | Life Questions | question bank, profile |
| "Help me say something to my daughter" | Wish I Had Said | loved ones, answers |
| "What about my final days?" | Last Days Planner | healthcare answers, loved ones |
| Building or rebuilding the plan | Plan Builder | everything in answers/ and plan/ |
| "Send this to my son" | Share The Plan | the plan, loved ones, explicit consent |
| A hard day, a diagnosis, a funeral | Hard Moments | helplines, the person in front of it |
| Playlists and life celebrations | Memory Playlist | answers, loved ones |

Shared folder conventions:

```
shared/profile.md          who the person is (written at onboarding, editable anytime)
shared/loved-ones.md       the people this plan serves
shared/answers/            one markdown file per area + progress.json
shared/plan/               reflection.md, letters/, last-days.md, playlists.md,
                           EPILOGUE-LIFE-PLAN.md, epilogue-life-plan.html, shared-log.md
```

Rules between skills: read before writing; never overwrite a person's own words without showing the change first; progress.json is the single source of truth for question progress; the plan rebuilds on request, never automatically mid-thought.
