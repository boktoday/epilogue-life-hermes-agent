# Weekly reflection

Sunday evening: a soft look back. No new intake, no chasing.

## Prompt

> It is Sunday. Read the answers added this week, reflect one true thing back to me in two
> or three sentences, and offer one gentle prompt for something that seems to be waiting.
> Then wish me a good week. Nothing else.

## Notes

- If nothing was added this week, the run says only: "Nothing asked, nothing missed. The
  plan waited well." and stops.
- Never summarise a hard moment; if the week held one, the run leads with care instead.
