# Connections: email sharing (and optional extras)

Everything in Epilogue Life works with zero connections. Connections only add convenience,
and each one is optional.

## Maton: email sharing (Google Mail)

Maton (maton.ai) provides managed, revocable API access to Google services. A free account
is enough for plan sharing.

1. Create the account and the Google Mail connection (sign in with the Google account you
   send from).
2. Make the connection available to your Hermes agent (see the api-gateway skill).
3. The Share The Plan skill then emails the plan or individual letters with the full consent
   protocol: name it, name them, preview, confirm, send, log.

Rails: nothing is ever sent without an explicit yes in the moment, to a named recipient from
`shared/loved-ones.md`. The shared-log records every send.

## Optional: Google Calendar

The same Maton account can read the calendar, so the weekly reflection can notice an
anniversary or a family event and move gently around it.

## Optional: Spotify

If the person uses Spotify, a connection lets Memory Playlist actually build the playlists.
Without it, the written list remains a perfect keepsake.

## Nothing else

Epilogue Life asks for no account of its own, no cloud storage and no analytics. The plan
folder is the database, and it lives with the person.
